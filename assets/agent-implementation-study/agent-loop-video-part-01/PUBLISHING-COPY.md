## 推荐标题

LLM 和 Agent 到底差在哪？

## 备选标题

1. 为什么你的 AI 还只是一个搜索框？
2. 模型没有变强，为什么却能替你工作？

## 正文

很多人现在使用大模型的方式，和使用搜索引擎差不多：打开对话框，输入问题，等它给出答案。

但一个模型本身，只负责根据当前上下文生成下一段输出。它不会自己观察你的电脑，也不会因为说出“打开链接”，就真的让浏览器发生变化。

视频里我用了一个供应商比价的例子。第三家供应商只有一个商品链接，模型缺少信息，于是让你打开网页、读取内容，再把结果贴回对话框。我们平时觉得很自然的这几步，其实就是一次完整的判断、行动和观察。

如果把这段人工交接交给外部系统和工具，并把执行结果送回模型，下一轮判断就能自动开始。一次次独立的模型生成，也就被连接成了可以持续工作的 Agent。

所以，LLM 和 Agent 的差别，不只是模型能力变强了，更重要的是工作方式变了。
